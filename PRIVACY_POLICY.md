# Политика конфиденциальности — Meet Transcript Export

Дата вступления в силу: 2 октября 2026 г.

## Какие данные обрабатывает расширение

Meet Transcript Export захватывает текст живых субтитров (closed captions),
отображаемых Google Meet во время встречи, и сохраняет его **локально на
устройстве пользователя** с помощью стандартного браузерного хранилища
(`chrome.storage.local`).

## Передача данных третьим лицам

Расширение **не отправляет никакие данные на внешние серверы**. У расширения
нет собственного backend, аналитики, трекеров или сторонних сервисов. Весь
захваченный текст субтитров остаётся в браузере пользователя и покидает
устройство только тогда, когда пользователь сам явно экспортирует
транскрипцию в файл с помощью разрешения `downloads` (сохранение файла на
диск пользователя — не отправка куда-либо).

## Используемые разрешения

- **storage** — для локального сохранения захваченных субтитров между
  сессиями, чтобы их можно было просмотреть и экспортировать позже.
- **downloads** — для сохранения экспортированной транскрипции в виде файла
  на диск пользователя по его запросу.
- **Доступ к хосту `https://meet.google.com/*`** — чтобы скрипт расширения
  мог считывать элементы субтитров на странице встречи Google Meet. Никакие
  другие сайты не затрагиваются.

## Хранение и удаление данных

Данные хранятся локально в браузере пользователя. Пользователь может удалить
их в любой момент, удалив расширение или очистив его данные через настройки
Chrome (`chrome://extensions`).

## Удалённый код

Расширение не загружает и не исполняет код из внешних источников. Все
скрипты входят в пакет расширения и проходят проверку Chrome Web Store.

## Изменения политики

При изменении обработки данных текст политики будет обновлён, а новая версия
расширения будет содержать актуальную ссылку.
